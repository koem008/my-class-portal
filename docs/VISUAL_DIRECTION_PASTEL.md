# Vizuální směr: výrazné pastelové barvy

Aplikace má působit pozitivně, přátelsky a vizuálně výrazně. Základ tvoří světlé pastelové plochy s dostatečným kontrastem textu, nikoli šedobéžová administrace.

## Paleta
- mátová / tyrkysová: hlavní pracovní a potvrzovací akce
- levandulová / fialová: AI, kreativita, asistence
- meruňková / korálová: upozornění, aktivita, energie
- světle žlutá: příprava, nápady, zvýraznění
- blankytně modrá: kalendář, informace, přehled
- růžová: jemné sekundární zvýraznění

Barvy mají být pastelové, ale viditelné a sytější než dosavadní téměř bílé tóny. Velké plochy mohou používat vícebarevné pastelové gradienty. Karty mají mít vlastní barevný charakter a nemusí být všechny bílé. Tmavý text zůstává kvůli čitelnosti.

## Zásady
- žádný generický šedobéžový admin dashboard
- větší barevné plochy, ne jen malé barevné ikonky
- každá hlavní sekce může mít vlastní pastelový akcent
- rozhraní musí zůstat profesionální a dobře čitelné
- tiskové/PDF výstupy se vizuálním tématem aplikace nemění
