# Phase 1 — Scope lock

Phase 1 je uzamčena na datovou a bezpečnostní vrstvu.

Povolený scope:

- PostgreSQL/Supabase schéma,
- autentizační vazby,
- tenant isolation,
- RLS,
- pseudonymní student model,
- databázové constrainty,
- bezpečnostní testy,
- odpovídající generované typy po aplikaci schématu.

Zakázaný scope:

- dashboard,
- vizuální redesign,
- kurikulární obsah,
- AI orchestrace,
- hlas,
- generování materiálů,
- Lesson Engine,
- exporty.
