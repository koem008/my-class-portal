# Moje třída — vizuální směr

Cíl: pozitivní, klidné, svěží a profesionální rozhraní pro každodenní práci učitele. Ne infantilní, ne sterilní admin dashboard.

Principy:
- světlé teplé pozadí a měkké pastelové akcenty;
- hlavní barva: hlubší modrozelená pro důvěru a klid;
- doplňkové akcenty: meruňková, levandulová, mátová, světle modrá;
- velké vzdušné karty, měkké stíny, kvalitní spacing;
- pozitivní mikrocopy bez marketingové vaty;
- žádné falešné statistiky;
- vysoká čitelnost a perfektní čeština;
- desktop/tablet jako hlavní pracovní plocha, mobil optimalizovaný pro rychlou orientaci a hlas.

Hlavní obrazovka Dnes má během několika sekund odpovědět: co mě dnes čeká, co je připravené a kde mi může AI ušetřit čas.
